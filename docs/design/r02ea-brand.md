# WHYFI brand identity

**Route Focus is the approved WHYFI mark for R02E-A.** A two-node path crosses a pair of inspection corners and suggests a connection under test. At small sizes the diagonal carries the silhouette.

The color mark uses the workspace cyan and raised neutral. The monochrome version uses a white glyph on a near-black tile. The app header pairs the mark with visible WHYFI text and treats the image as decorative.

- [Color source](../../desktop/public/whyfi.svg)
- [Monochrome source](whyfi-mark-monochrome.svg)

From `desktop`, run `npm run tauri -- icon public/whyfi.svg --output ../build/whyfi-icons` with existing dependencies. Copy only the filenames already tracked in `src-tauri/icons` into that directory. Keep mobile outputs out of the Windows-first workspace.

The browser and native window titles use WHYFI. The bundle product name, identifier, version, and icon filenames retain their current packaging values.
